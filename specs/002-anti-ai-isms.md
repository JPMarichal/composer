# Especificación: Safeguards Anti-AI en Composición Lírica

Basado en Wikipedia:Signs of AI writing (WikiProject AI Cleanup), repositorios humanizer/blader y avoid-ai-writing/conorbronsdon. Investigación ampliada con tropes.fyi, Jack Righteous, Suno Wiki, aismells.com, Deezer Research (ISMIR 2025), Reddit r/udiomusic y r/WritingWithAI.

## Problema

La canción "Velocidad Cero" sonó a IA. Identificar y corregir los patrones que delatan origen sintético.

---

## 1. Léxico sobreuso por la IA (palabras quemadas)

## 2. Patrones sintácticos que delatan IA

| Patrón                       | Ejemplo IA                                                          | Alternativa humana            |
| ---------------------------- | ------------------------------------------------------------------- | ----------------------------- |
| Parallel negation encadenada | "no sé... no puedo... no tengo"                                     | Mezclar afirmación y negación |
| Negative parallelism         | "No es X, es Y" / "No es una despedida, es un hasta luego"          | Decir "me voy" sin florituras |
| "Not X. Not Y. Just Z."      | "No es un error. No es un fracaso. Es un aprendizaje"               | "Aprendí"                     |
| "The X? A Y." retórica       | "El resultado? Devastador"                                          | "Fue devastador"              |
| Rule of threes (tríada)      | "correr, gritar, avanzar" — la IA nunca hace binarios               | Dos elementos o uno           |
| Em dash como coletilla       | — usado 4+ veces en una canción                                     | Punto, coma o nada            |
| Metáfora sobre-explicada     | "como un barco a la deriva, sin rumbo ni puerto" en el mismo verso  | Dejar la imagen sin explicar  |
| Inflated symbolism           | el verso entero es una metáfora hinchada sin apoyo concreto         | Hablar de algo real           |
| "Serves as" construction     | "la noche sirve como recordatorio" (calco del inglés)               | "la noche recuerda"           |
| Anaphora abuse               | "Y el viento... Y el mar... Y el sol..." 3+ versos seguidos iguales | Una vez, no más               |
| Bullet points / listas       | Varias enumeraciones en la misma canción                            | No enumerar                   |
| Etiquetar figuras retóricas  | "una metáfora", "un símil" en la letra                              | Usar la figura sin nombrarla  |

## 3. AI-ismos semánticos (palabra incorrecta en contexto)

El error crítico: la IA elige palabras _técnicamente posibles_ pero _pragmáticamente absurdas_. Ejemplo clásico: "la luna está tiesa". Tiesa significa rígida, como un cadáver. La luna no puede estar tiesa. La IA eligió "tiesa" por ser palabra menos común, tratando de sonar creativa, pero falla porque no hay un hablante nativo atrás.

| AI-ismo semántico       | Problema                                            | Alternativa real                           |
| ----------------------- | --------------------------------------------------- | ------------------------------------------ |
| la luna está tiesa      | tiesa = rígido/cadáver, no aplica a luna            | la luna está fija, redonda, blanca, mustia |
| el silencio llora       | silencio no llora, es una metáfora forzada sin base | el silencio pesa, se oye, aprieta          |
| el tiempo se desangra   | metáfora médica sin contexto que la justifique      | el tiempo pasa, se arrastra, vuela         |
| la noche me abraza      | cliché máximo de IA: noche + abrazo juntos          | la noche me envuelve, me tapa              |
| el dolor baila          | bailar requiere alegría, la IA fuerza contraste     | el dolor late, duele, queda                |
| el viento susurra       | susurrar es humano; personificación perezosa        | el viento silba, empuja, corta             |
| recuerdos que gritan    | grito asociado a dolor agudo; mezcla metáforas      | recuerdos que vuelven, pesan               |
| el fuego me congela     | oxímoron forzado sin justificación poética          | el fuego quema, calienta, arde             |
| caminar sobre las aguas | referencia bíblica gastada                          | cruzar, pasar, seguir                      |
| volar sin alas          | IA lo usa automáticamente para "libertad"           | volar, simplemente                         |

Regla de oro: **Si un hablante nativo en un bar no diría esa frase, no la pongas en la canción.**

| Categoría           | Palabras                                                                                             |

| Faux-deep verbs     | delve, embark, elevate, navigate, foster, unveil, harness, cultivate, grapple, embrace               |
| Vague intensifiers  | very, truly, incredibly, remarkably, utterly, profoundly, deeply, seamless                           |
| Corporate/formalese | leverage, utilize, optimize, streamline, paradigm, facilitate, revolutionize                         |
| Result markers      | it's worth noting that, it is important to, it should be noted, in terms of                          |

| Passive shells      | it is believed that, it has been shown that, research suggests that, studies indicate                |

## 5. Palabras y fórmulas de sonido a IA específicas de Suno/Udio

(Compilado de Suno Wiki, Reddit r/udiomusic, Jack Righteous)

| AI-ismo                               | Explicación                                               |
| ------------------------------------- | --------------------------------------------------------- |
| "Ecos de..."                          | Aparece en >50% de letras de Suno según usuarios          |
| Luces de neón                         | Tan común que es meme en la comunidad Suno                |
| "(oh-oh)" en cada chorus              | IA pone ad-libs genéricos siempre iguales                 |
| "Story unfolds"                       | Calco narrativo automático                                |
| Puente con "Pero"                     | El puente IA siempre empieza con "But" o "Pero"           |
| Outro con fade out genérico           | "fade out" sin contenido real de cierre                   |
| Pre-Chorus que termina en pregunta    | IA estructura pre-coro sistemáticamente con interrogación |
| Título repetido 4+ veces en el chorus | IA sobre-refuerza el hook                                 |

## 6. Safeguards cuantificables para el prompt

1. **30%+ rimas asonantes o libres** — contar sobre total de versos que riman
2. **Máximo 1 tríada (rule of threes) por canción**
3. **0 em dashes consecutivos** — cero uso de — como recurso
4. **≥1 coloquialismo por estrofa** — contracciones, vulgarismos, muletillas
5. **≥1 verso con métrica quebrada** — sílaba de más o de menos voluntaria
6. **No etiquetar figuras retóricas** — no escribir "una metáfora", usarla
7. **Detalles sensoriales concretos (olor, temperatura, textura)** — al menos 1 por estrofa
8. **Verbos de acción sobre adjetivos** — proporción ≥2:1 verbos/adjetivos
9. **1 imagen absurda o surrealista por canción** — algo que no encaje del todo
10. **Cero palabras del listado de léxico sobreuso** (sección 1)
11. **Cero AI-ismos semánticos** (sección 3): cada adjetivo debe funcionar en contexto real
12. **Cero negative parallelism** ("No es X, es Y"): detectado como el AI-ismo #1 global
13. **Sin parallel negation encadenada**: alternar negación con afirmación
14. **Sin anaphora abuse**: máximo 1 anáfora de 2 versos en toda la canción

## 7. Validación post-generación

```js
function validate(song) {
  const prohibitedWords = [
    "ecos?",
    "susurr",
    "neón",
    "elevar",
    "ascender",
    "gracia",
    "abrazo",
    "jungla de concreto",
    "sueños rotos",
    "noche eterna",
    "sombras",
    "latidos",
    "destellos",
    "sendero",
    "llama que arde",
    "tempestad",
    "vacío",
    "abismo",
    "puentes",
    "muros",
    "cicatriz",
  ];
  const result = {
    asonantesOK: asonantes(song) / totalRimas(song) >= 0.3,
    sinEmDash: !song.includes("—"),
    sinNegativePar: !song.match(/no\s+es\s+\w+\s*,\s*es\s+/i),
    triadas: countTriadas(song) <= 1,
    coloquialismos: coloquialismos(song) >= estrofas(song),
    metricaQuebrada: countMetricaQuebrada(song) >= 1,
    proporcionVerbos: verbos(song) / adjetivos(song) >= 2,
    imagenAbsurda: countAbsurdo(song) >= 1,
    zeroProhibitedWords: !prohibitedWords.some((w) =>
      new RegExp(w, "i").test(song),
    ),
    zeroSemanticAIisms: checkSemanticAIisms(song),
    sinAnaphoraAbuse: maxAnaphoraLength(song) <= 2,
    sinParallelNegation: !song.match(/(no\s+\w+\s*,\s*no\s+\w+\s*,\s*no\s+)/i),
  };
  return result;
}
```
