# Pitch Editorial para Spotify

## Objetivo

Documentar cómo debe redactarse un pitch editorial para Spotify a partir de fuentes oficiales de Spotify y guías serias del sector musical.

## Conclusión ejecutiva

Un pitch editorial de Spotify **no** debe escribirse como bio, carta formal, nota de prensa completa ni texto promocional para fans.

Debe escribirse como un resumen operativo para un editor ocupado:

1. **Qué suena** — subgénero, mood, energía, instrumentación distintiva.
2. **Qué cuenta o qué sensación captura** — historia, imagen, conflicto o escena de escucha.
3. **Dónde encaja** — momento de consumo, lane editorial plausible, audiencia y contexto cultural/geográfico si aplica.
4. **Qué respaldo real tendrá** — video, clips, prensa, campaña, gira, creators, pre-saves, tracción previa o lanzamiento coordinado.

La regla dominante es: **claridad, precisión, contexto y honestidad**.

## Qué sí debe incluir

### 1. Identidad sonora real

- Género y subgénero concretos
- Mood principal y secundario
- Instrumentos o rasgos sonoros distintivos
- Idioma y contexto cultural si aplica

Ejemplo:

> Indie pop nocturno con synths cálidos, batería contenida y una voz íntima.

### 2. Contexto narrativo o emocional

- Qué motivó la canción
- Qué escena de escucha representa
- Qué emoción específica transmite
- Qué imagen mental ayuda a entenderla rápido

Ejemplo:

> Escrita después de una despedida sin cierre, captura el trayecto de vuelta a casa cuando sigues repasando una conversación en la cabeza.

### 3. Encaje editorial

- Momento de escucha
- Tipo de audiencia
- Lane editorial razonable
- Afinidad con playlists por mood, nicho, región o escena

Ejemplo:

> Encaja en late-night indie, mellow drive, sad commute o playlists de pop introspectivo.

### 4. Señales de soporte o momentum

- Video o live session
- Plan de clips o contenido corto
- Campaña de pre-save
- Tour o fechas
- Prensa confirmada
- Datos orgánicos previos: saves, streams, playlist adds, crecimiento, si existen

Ejemplo:

> El lanzamiento irá acompañado de 6 clips verticales, una live session y campaña de pre-save durante la semana previa.

## Qué no debe incluir

- Suplicar placement
- Decir que el track es un “hit”
- Afirmar que es “mi mejor canción”
- Llenar el texto de adjetivos vacíos
- Escribir una mini biografía del artista
- Listar demasiadas playlists grandes por ambición
- Usar tags falsos para “abrir más puertas”
- Redactar como email corporativo o carta formal

## Estructura recomendada

La mejor estructura observada en las fuentes revisadas es de **3 a 4 frases**:

1. **Identidad sonora**
2. **Historia o emoción**
3. **Encaje editorial / momento de escucha**
4. **Soporte real del lanzamiento**

## Primera pasada obligatoria

La primera redacción no debe cerrarse con una sola opción. El documento inicial de trabajo debe incluir:

1. **Borrador maestro**
2. **Tres variaciones** con ángulos distintos
3. **Versión final elegida**

Las variaciones no son texto extra para el editor; son parte del proceso interno para comparar enfoques antes de enviar una sola versión final.

Ángulos recomendados para esas tres variaciones:

- **Sonido primero**: abre con la identidad sonora
- **Historia primero**: abre con la imagen o conflicto
- **Fit primero**: abre con el momento de escucha o lane editorial

## Fórmula maestra

Usar esta lógica al redactar:

```text
[SONIDO] + [HISTORIA/EMOCION] + [MOMENTO/FIT] + [SOPORTE REAL]
```

Ejemplo condensado:

> Single de indie pop melancólico con synths suaves, batería contenida y voz cercana. Nace de una despedida sin cierre y trabaja esa sensación de volver solo de noche con la conversación todavía encima. Encaja en late-night indie, mellow pop y sad commute. El lanzamiento tendrá clips verticales, pre-save y una live session en release week.

## Reglas de redacción

- **Escribir como editor para editor**, no como fan para fan.
- **Nombrar cosas auditivas concretas**, no solo emociones abstractas.
- **Ayudar a clasificar**, no a impresionar.
- **Ser específico sin sobreactuar**.
- **No inventar tracción**.
- **Usar un tono factual y vivo**.
- **Cada frase debe ganar su lugar**.

## Metadatos que hay que alinear con el texto

El texto del pitch debe estar alineado con los campos del formulario de Spotify for Artists:

- Género
- Subgénero
- Mood
- Estilos
- Instrumentos
- Idioma
- Cultura / localidad
- Tipo de grabación
- Ciudad de origen y base actual

Si el texto dice una cosa y los metadatos dicen otra, el pitch pierde credibilidad y puede rutearse al editor equivocado.

## Timing recomendado

### Mínimo oficial

- **7 días antes del lanzamiento** para elegibilidad de revisión editorial y control del tema que entra a Release Radar.

### Recomendación práctica

- **3 a 4 semanas antes**.
- Idealmente, distribuir **4 a 5 semanas antes** para que el release aparezca con tiempo en Spotify for Artists.

## Perfil del artista: impacto indirecto

Aunque el pitch es el foco, las fuentes coinciden en que un perfil descuidado debilita el paquete completo.

Antes de pitchar, revisar:

- Bio actualizada
- Header y fotos profesionales
- Artist Pick
- Social links
- Canvas / Clips si están disponibles
- Coherencia visual con el lanzamiento

## Checklist operativo

### Antes de escribir

- [ ] El track ya fue distribuido y aparece en `Music > Upcoming`
- [ ] La fecha de salida deja al menos 7 días, idealmente 21-28
- [ ] El audio final está cerrado
- [ ] La portada final está cerrada
- [ ] El perfil de artista está actualizado
- [ ] Ya sé cuál es el foco del release
- [ ] Ya definí tres ángulos posibles para el pitch

### Antes de enviar

- [ ] El pitch dice qué suena en lenguaje concreto
- [ ] El pitch incluye historia, emoción o escena
- [ ] El pitch explica el momento de escucha o lane editorial
- [ ] El pitch menciona soporte real del lanzamiento
- [ ] El documento contiene tres variaciones iniciales comparables
- [ ] El pitch no parece bio ni carta formal
- [ ] El pitch no usa hype vacío
- [ ] Los metadatos coinciden con el texto
- [ ] No se prometen resultados ni se mendiga placement

### Después de enviar

- [ ] Guardé el texto del pitch en un archivo local
- [ ] Registré fecha de envío y release date
- [ ] Anoté tags usados
- [ ] Anoté el plan de promoción asociado
- [ ] Revisaré luego saves, follows, playlist adds y source of streams

## Criterio final

Si un editor pudiera leer solo cuatro cosas del pitch, deberían ser estas:

1. **Qué es el track en términos sonoros**
2. **Qué experiencia emocional propone**
3. **Dónde encaja de forma natural**
4. **Qué actividad real lo respalda al salir**
