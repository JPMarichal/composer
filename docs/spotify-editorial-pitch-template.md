# Plantilla Maestra — Pitch Editorial Spotify

## Naturaleza del pitch

Este texto está pensado para **revisión editorial interna en Spotify for Artists**.
No es visible para el público como descripción de lanzamiento, bio o copy promocional.
Debe escribirse para ayudar al editor a clasificar el track con rapidez, no para venderlo al oyente final.

## Instrucciones de uso

- Mantener cada variación y la versión final en **1 párrafo corto** o **4 frases máximas**.
- Priorizar especificidad sonora y contextual.
- No usar hype vacío.
- No escribir una bio.
- No prometer resultados.
- No listar playlists gigantes “por si acaso”.
- En la primera pasada, redactar **3 variaciones** dentro del mismo documento antes de elegir la versión final.
- Salvo razón fuerte en contra, la **versión final recomendada** debe partir de **sonido primero**.

## Fórmula

```text
[SONIDO] + [HISTORIA/EMOCION] + [MOMENTO/FIT] + [SOPORTE REAL]
```

## Plantilla breve

```text
"[TITULO]" es un/a [SUBGENERO] con [ELEMENTOS SONOROS CLAVE].
Nace de [HISTORIA / DETONANTE / IMAGEN], y transmite [EMOCION / TENSION / MOMENTO].
Encaja en [MOMENTO DE ESCUCHA / LANE EDITORIAL / TIPO DE AUDIENCIA].
El lanzamiento contará con [VIDEO / CLIPS / PRE-SAVE / PRENSA / SHOWS / CAMPAÑA / TRACCION REAL].
```

## Plantilla compacta

```text
[TITULO] es un/a [SUBGENERO] con [SONIDO CLAVE]. Escrita a partir de [DETONANTE], captura [EMOCION/ESCENA]. Encaja en [LANE/MOMENTO]. El release tendrá [SOPORTE REAL].
```
