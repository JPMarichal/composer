# La oficina de objetos perdidos — Canvas prompts poeticos para CapCut Seedance

## Objetivo

Segunda version de prompts para el album `La oficina de objetos perdidos`, con un enfoque menos literal y mas poetico. La intencion aqui no es ilustrar cada letra de forma obvia, sino sugerir una atmosfera simbolica y emocional que conviva con la cancion.

## Criterio de esta version

- menos relato explicito
- mas simbolo y clima
- menos acciones narrativas
- mas gestos, luz, objetos y tension emocional
- siempre usable para Seedance

## Sufijo comun recomendado

```text
vertical 9:16, 8-second seamless loop, cinematic, poetic, subtle motion, emotionally precise, no text, no subtitles, no logo, no watermark, no lip-sync, no talking to camera, no hard cuts, no chaotic motion
```

## Nota de uso

Esta version es mejor cuando se quiere un Canvas mas evocador y menos descriptivo. Si Seedance produce resultados demasiado vagos, conviene volver a la version base y recuperar una o dos anclas concretas: objeto, lugar o gesto.
