# La oficina de objetos perdidos — Canvas prompts para CapCut Seedance

## Objetivo

Documento de trabajo para generar Canvas verticales del álbum `La oficina de objetos perdidos` en CapCut usando el modelo Seedance. Primero consolida criterios de Canvas efectivos; después propone prompts específicos por canción.

## Hallazgos documentados

### 1. Qué debe ser un Canvas de Spotify

Hallazgos consolidados a partir de documentación local del repo y fuentes públicas del sector:

- Un Canvas es un loop visual vertical que reemplaza la portada estática en la vista `Now Playing`.
- La duración efectiva aceptada se repite en las fuentes consultadas: `3 a 8 segundos`.
- El formato repetido por fuentes oficiales y de distribución es `9:16 vertical`.
- Las especificaciones más repetidas son `MP4` o `JPG`, con altura mínima de `720 px`; varias guías recomiendan trabajar a `1080 x 1920`.
- El Canvas debe funcionar como loop natural, no como mini videoclip con principio y final bruscos.

### 2. Recomendaciones creativas que más se repiten

- El Canvas funciona mejor cuando desarrolla una sola idea visual clara.
- Los mejores resultados suelen venir de movimiento sutil y continuo, no de cortes rápidos.
- Conviene mantener el sujeto principal centrado o dentro de una zona segura, porque la interfaz de Spotify puede tapar bordes.
- Las fuentes coinciden en evitar texto, logos, subtítulos, interfaces y elementos que parezcan anuncio.
- También se repite la recomendación de evitar bocas cantando, hablando o rapeando, salvo que sea una decisión muy controlada.
- Los loops suaves, con entrada y salida visualmente parecidas, suelen rendir mejor que los clips con narrativa cerrada.
- El primer segundo importa mucho: debe haber un anzuelo visual inmediato, aunque sea pequeño.
- El Canvas no debe competir con la canción; debe ampliar su atmósfera.
- A nivel de catálogo, conviene mantener coherencia visual entre tracks del mismo álbum.

### 3. Traducción práctica para Seedance

Para este álbum, la mejor estrategia no es pedir escenas sobrecargadas. Conviene pedir:

- un solo escenario principal por canción
- una acción física leve y repetible
- cámara lenta o casi fija
- luz, textura y objetos concretos
- final parecido al inicio para favorecer loop
- cero texto en pantalla

### 4. Ajustes sugeridos en CapCut

- Modelo: `Dreamina Seedance 2.0` o la variante Seedance disponible en la cuenta.
- Modo: `Text to video`.
- Relación de aspecto: `9:16`.
- Duración sugerida: `6 s`.
- Variantes por prompt: `4`.
- Intensidad de movimiento: `baja` o `media-baja`.
- Prioridad: continuidad, claridad del sujeto, atmósfera.
- Evitar: texto, logos, watermark, UI, subtítulos, lip sync, cambios bruscos de plano, flicker, morphing de manos, caras deformes.

### 5. Criterio curatorial para este álbum

`La oficina de objetos perdidos` pide una línea visual unificada: memoria material, umbrales, objetos guardados, estaciones vacías, luz de tarde, interiores con polvo noble, ciudad melancólica, y movimiento pequeño con carga emocional. La familia visual del álbum debe sentirse como un archivo de cosas que no regresan.

## Recomendaciones finales de uso

- Generar varias versiones por canción y elegir la que mejor haga loop, no la más espectacular.
- Si Seedance devuelve demasiada acción, simplificar el prompt y reforzar `subtle motion`, `slow camera`, `single clear subject`.
- Si aparecen labios cantando o acting excesivo, eliminar presencia humana directa y volver a objetos, siluetas o reflejos.
- Mantener una paleta común entre tracks: ámbar, azul noche, crema envejecido, rojo clavel, tungsteno, neón suave.
- Para uniformidad de álbum, conviene exportar todos a `1080 x 1920` y priorizar acabado cinematográfico realista antes que look AI llamativo.
